# Loggy

🕹️ Project DoomStealer (Loggy v2)DoomStealer es un proyecto de investigación en ciberseguridad que demuestra el concepto de Ingeniería Social combinada con un Infostealer de última generación. El script utiliza un juego clásico (DOOM) como señuelo (decoy) mientras ejecuta tareas de monitoreo y exfiltración de datos en segundo plano, utilizando Discord como centro de mando y control (C2).🚀 Características PrincipalesDecoy Activo: Ejecución de DOOM (1993) en el navegador mediante Ingeniería Social.Stealer Multi-Perfil: Exfiltración recursiva del historial de navegación de Chrome y Edge (soporta múltiples perfiles).Keylogger Inteligente: Captura de teclas con rastreo de ventana activa (contexto de aplicación).Vigilancia Multimedia: Captura de cámara web, grabación de micrófono y capturas de pantalla.Bypass de AV: Captura de pantalla procesada 100% en RAM (io.BytesIO) para evadir escaneo de archivos.Anti-Forense: Ocultamiento de archivos temporales mediante la API del Kernel de Windows.🛠️ Requisitos e Instalación1. Preparación del C2 (Discord)Crea un servidor de Discord.Crea un Bot en el Discord Developer Portal.Habilita todos los Privileged Gateway Intents (Presence, Server Members, Message Content).Invita al bot a tu servidor con permisos de Administrador.2. Instalación de DependenciasAsegúrate de tener Python 3.10+ instalado. Luego, instala las librerías necesarias:Bashpip install discord.py opencv-python sounddevice scipy pyautogui requests pygetwindow pynput mss python-docx pillow
